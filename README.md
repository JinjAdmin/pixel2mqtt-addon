# pixel2mqtt Home Assistant add-on

[![Add repository to my Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FJinjAdmin%2Fpixel2mqtt-addon)

Add-on repository for [pixel2mqtt](https://github.com/JinjAdmin/pixel2mqtt), the bridge and web editor for
Govee H6631 pixel displays running the [pixeld-h6631](https://github.com/JinjAdmin/pixeld-h6631) firmware.

**Install:** use the button above, or in Home Assistant go to Settings → **Apps** → **Install app** → ⋮ →
**Repositories** and add `https://github.com/JinjAdmin/pixel2mqtt-addon`. Then install **pixel2mqtt**.
(Older Home Assistant versions call these *add-ons*: Settings → Add-ons → Add-on Store → ⋮ → Repositories.)

Tested on Home Assistant OS 2026.11 on a Raspberry Pi 5. Images are built for amd64 and aarch64.

Running Home Assistant in a container instead? Use the Docker image directly; see the pixel2mqtt README.
